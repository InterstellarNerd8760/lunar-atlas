# Browser assets

Place finished terrain and texture exports here. Store each asset's provenance and decoding parameters alongside it in `metadata/`.

`site-photos/` holds one licensed photograph per landing site or Artemis region, with captions and credits in `site-photos/index.json`. See `docs/CREDITS.md`.

`site-writeups.json` holds the site drawer writeups (about text, facts, and sources), keyed by catalog id.
