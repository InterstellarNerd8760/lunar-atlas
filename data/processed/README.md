# Processed Lunar Atlas datasets

These ZIP archives are the original notebook exports. Each contains source and georeferencing metadata.

- `apollo11-nac.zip` contains the Apollo 11 image crop and its georeferencing.
- `south-pole-lola.zip` contains a regional elevation grid and one terrain horizon profile.
- `south-pole-visibility.zip` contains long-term sunlight, Earth visibility, and permanent shadow grids and previews.

Extract each ZIP into its own directory for inspection or integration. The viewer needs dedicated loaders for these exports. The normalized global WAC texture is a separate export.
